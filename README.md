# لقطة · Blocking

أداة بسيطة على الآيفون لعمل **Blocking** للمشاهد السينمائية قبل توليدها بالذكاء الاصطناعي.
الأولوية: **التحكم بالكاميرا + حركة الكاميرا بالمفاتيح (Keyframes)**.

كل شي بيشتغل محليًا بالمتصفح. ما في سيرفر ولا حساب ولا سحابة.

**الرابط:** `https://yahia4262714g-design.github.io/laqta/`

## التنصيب على الآيفون

1. افتح الرابط من **Safari**.
2. زر المشاركة ← **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.
3. بيظهر تطبيق اسمه **لقطة** وبيفتح بملء الشاشة، وبيشتغل بدون إنترنت بعد أول فتحة.

> المشاريع المحفوظة داخل التطبيق (من الشاشة الرئيسية) منفصلة عن المحفوظة بـ Safari نفسه. اشتغل من مكان واحد.

## طريقة الشغل

### الكاميرا
| الحركة | النتيجة |
|---|---|
| إصبع واحد | Orbit حول الهدف |
| إصبعين سحب | Pan / Truck / Pedestal |
| قرص | Dolly In / Out |
| وضع **التفاف** | الكاميرا بتلف بمكانها (Pan / Tilt) |
| زر **أزرار** | أمام / خلف / يمين / يسار / فوق / تحت (اضغط مطولًا) |
| **العدسة** | 14 → 135mm + ميلان Dutch |
| **الهدف** | قفل نظر الكاميرا على عنصر حتى لو تحرك |
| **أرقام** | المكان والاتجاه والهدف بالأرقام (اختياري) |

### مفاتيح الكاميرا
1. حط الكاميرا ← **◆ إضافة مفتاح كاميرا**.
2. حرّك المؤشر بشريط الوقت للثانية 3 ← غيّر الكاميرا ← **◆**.
3. كرر. اضغط ▶ والكاميرا بتتحرك لحالها بين المفاتيح.

- نقرة على مفتاح = انتقال له. سحبه = تغيير وقته.
- **ناعم** (الافتراضي) أو **خطي** لكل مفتاح.
- لما الكاميرا تتغير وما تنحفظ، زر المفتاح بينبض.
- كل مفتاح بيحفظ **هدفه**: لحركة "الكاميرا تمشي والعين على السيارة" اقفل الهدف على السيارة واختار "قفل كل المفاتيح".

### حركة العناصر (نفس فكرة مفاتيح الكاميرا)
1. تبويب **مجسمات** ← اضغط على العنصر.
2. **◆ مفتاح حركة للعنصر** (أو `K` على الكمبيوتر) بمكان البداية.
3. حرّك المؤشر بشريط الوقت للثانية اللي بدك ← انقل العنصر (تحريك / تدوير / حجم). **المفتاح بينحفظ لحاله.**
4. كرر لأي عدد نقاط. اضغط ▶ والعنصر بيمشي على المسار.

- مفاتيح العنصر بتظهر بلونه على صف "مجسمات" بشريط الوقت: نقرة = انتقال، سحب = تغيير الوقت.
- **ناعم** أو **خطي** لكل مفتاح، والدوران بياخد أقصر طريق (سيارة بتلف).
- المشاريع القديمة اللي فيها حركة A → B بتتحول لحالها لمفتاحين.

### صورة المنتج الحقيقي
تبويب **مجسمات** ← **صورة منتج** ← اختار **لوحة مسطحة** (كرتونة، بوستر، أي منتج من قدّام) أو **علبة / قنينة** (الصورة بتلف على الوجه الأمامي للأسطوانة) ← اختار الصورة.

- الصورة بتطلع **بألوانها الحقيقية بدون إضاءة**، فالتغليف واللوغو بيضلوا متل ما هم بالكادر.
- الأفضل **PNG بخلفية شفافة**. الطول الافتراضي 30 سم للوحة و15 سم للعلبة؛ غيّره من "حجم" أو "أرقام".
- **تبديل الصورة** و**لوحة/أسطوانة** من أزرار العنصر المحدد.
- الصور محفوظة على الجهاز (IndexedDB) ومش جوّا نص المشهد؛ إذا نقلت المشهد لجهاز تاني بتطلع لوحة "الصورة مش موجودة" وبتبدّلها.

### وصف الحركة للبرومبت
القائمة ☰ ← **وصف الحركة للبرومبت**: نص إنجليزي محسوب من مفاتيحك، لكل مقطع بالثواني: حجم اللقطة، زاوية الكاميرا، العدسة، ونوع الحركة (Track / Lead / Overtake / Orbit / Crane / Dolly / Pan…) وسرعتها، وحركة العناصر (مع كشف الـ Slow Motion). بيقترح كمان وين لازم يكون **قطع** إذا الكاميرا بتنتقل بسرعة كبيرة. انسخه للبرومبت مع الفيديو المرجعي.

### مشهد جاهز من Claude (نسخ ولصق)
1. القائمة ☰ ← **لصق مشهد من Claude** ← **نسخ التعليمات لـ Claude**.
2. الصقها بأي محادثة مع Claude (من الآيفون أو الكمبيوتر) واكتب تحتها اللقطة اللي بدك.
3. انسخ رد Claude، الصقه بالمربع، واضغط **استيراد المشهد**. بينفتح كمشروع جديد والقديم بيضل محفوظ.

- التعليمات فيها المشهد الحالي، فـ Claude بيقدر يعدّل عليه بدل ما يبدأ من الصفر.
- **نسخ المشهد كنص** بينسخ المشهد الحالي لحاله (للنسخ الاحتياطي أو نقله لجهاز تاني).
- إذا في غلط بالنص، التطبيق بيقلك وين بالضبط (مثلًا: "العنصر car: pos لازم يكون 3 أرقام").

### مدة المشهد
زر الساعة تحت ← أي مدة من **1 لـ 120 ثانية**: `−` / `+` ثانية ثانية (اضغط مطولًا للعد السريع)، أو السلايدر، أو اكتب الرقم. شريط الوقت فيه خط لكل ثانية.

### المعاينة والتصدير
- **معاينة الكاميرا**: بتعرض اللقطة النهائية بالنسبة المختارة (9:16 / 16:9 / 1:1).
- **تسجيل**: بيسجّل اللقطة من 0 للنهاية كفيديو (MP4 على الآيفون، 1080p) لترفعه كمرجع حركة لـ Kling / Seedance / غيرهم.
